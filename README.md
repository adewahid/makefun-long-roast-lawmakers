One satirical sentence, at most 320 characters, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF, for [The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) on make.fun.

`main.ts` writes the line to `/output/entry.txt`:

> The senator who wrote a 400-page bill to regulate the internet just emailed the committee a screenshot of his Word document pasted into another Word document, saved as 'final_FINAL_v2_REAL.pdf.docx'.

Run it with Node 22:

```sh
node main.ts
```
